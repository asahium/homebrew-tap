# asahium/homebrew-tap

```sh
brew install --cask asahium/tap/kveikur
```

| Cask | |
| --- | --- |
| [kveikur](https://github.com/asahium/kveikur) | Native macOS music player for music kept in folders. |

Kveikur is ad-hoc signed rather than notarized, so the cask clears the quarantine flag after installing.
