# asahium/homebrew-tap

```sh
brew tap asahium/tap
brew trust --tap asahium/tap
brew install --cask asahium/tap/kveikur
brew install --cask asahium/tap/inni
```

| Cask | |
| --- | --- |
| [kveikur](https://github.com/asahium/kveikur) | Native macOS music player for music kept in folders. |
| [inni](https://github.com/asahium/inni) | Anki-compatible flashcards with AnkiWeb sync. |

Both apps are ad-hoc signed rather than notarized, so the casks clear the quarantine flag after installing.
